How it works, and what it cannot do

  • It matches words, not meaning. Every mark on the right is a phrase in a rule set built from published scam warnings — 기관 사칭, 안전계좌, 인증번호 요구, 가족 사칭, 택배 사칭, 선입금 대출, 리딩방, 환급금.
  • It counts different kinds of pressure, not how bad a message is. A message with no marks is "no known pattern", never "safe".
  • It reads an address' shape without opening it: IP hosts, an "@" that hides the real host, punycode, shorteners, a bank's name sitting on a domain that is not the bank's.
  • It does not know your bank, your family, or whether a link is live. It cannot see images or PDFs, and it does not read Korean or English outside the phrases listed.

No account, no server, no analytics. The page loads once and works offline; you can check the source on GitHub and watch the network tab stay empty.

Second Read is a prototype, not an emergency service. If money has already left your account, call 112 (police) or 1332 (Financial Supervisory Service) — the numbers printed on those organisations' own websites.
